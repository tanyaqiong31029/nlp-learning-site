模块 01 · 规划

学习路线图

两条路线，两种人生节奏。默认突出语言学科研应用向——它能让绝大多数文科学习者在 3–5 个月内达到"研究够用"的水平。

⭐ 重点推荐

路线 A · 语言学科研应用向

周期 3–5 个月 每天 1–2 小时即可

目标：能用 Python 处理自己的语料、跑通文本分析实验、读懂 NLP 论文的"方法"部分，并把大模型当成靠谱（但需核查）的研究助手。

  1. Python 速成第 1–3 周

    在 Colab 里跑通第一个脚本；掌握变量、列表、字典、循环、函数"五件套"，标准是能改别人的代码。

  2. 数学急救包与第 1 步同步

    只学三样：向量、余弦相似度、概率直觉。高等数学暂且放到一边——真的用不到多少。

  3. 数据处理第 2 个月

    文件与 CSV 读写；用 numpy 算相似度，用 pandas 管理语料表格、做分组统计。

  4. 文本工具与 NLP 概念第 3 个月

    spaCy / stanza 分词与标注；搞懂词袋、TF-IDF、词向量、Token、Transformer 是什么、为什么行得通。

  5. 实操项目第 4 个月

    完成本站三个实验：Burrows-Delta 文体计量、文本相似度、语料统计——然后全部换上你自己的语料。

  6. 走向研究第 5 个月

    复现一篇计算人文 / 计量文体学论文的核心实验；学会把大模型用于辅助标注与写作，并知道如何防住它的幻觉。

路线 B · 算法研发向

周期 12–18 个月 需要大块时间投入

目标：能读懂论文公式、复现和改造模型，适合读博、转算法岗，或对模型内部原理有强烈好奇心的人。

  1. 高等数学第 1–2 月

    极限与连续、导数与偏导、链式法则、梯度——后面一切的地基。

  2. 线性代数第 3–4 月

    矩阵运算、秩、特征值与特征向量、SVD——这次要学"为什么"，不只是"是什么"。

  3. 概率论与统计第 5–6 月

    概率空间、常见分布、贝叶斯定理、假设检验与参数估计。

  4. Python 与工程基础第 6–7 月

    语法进阶、numpy、数据结构与算法入门、命令行与 Git。

  5. 机器学习第 8–10 月

    线性 / 逻辑回归、决策树、SVM、交叉验证与评估指标，配 Scikit-learn 实战。

  6. 深度学习第 11–13 月

    神经网络、反向传播、CNN/RNN、PyTorch 实战，亲手训练几个小模型。

  7. NLP 专精第 13–18 月

    词向量 → 序列模型 → Transformer → 预训练与微调 → 大语言模型，跟踪领域前沿。

模块 02 · 地基

数学基础

按 线性代数 → 概率论 → 高等数学 的优先级组织：线代决定你能不能看懂词向量和相似度，概率决定你能不能读懂语言模型和统计检验，高数只需要两个概念帮你理解"训练"在干嘛。

必学 推荐 了解即可 可跳过

① 线性代数 优先级 ★★★

在 NLP 的世界里，一切皆向量：文档、词、句子都会变成一串数字，而线性代数就是研究"一串数字怎么算"的学问。

向量是什么

必学

一串按顺序排好的数字，比如 [2, 1, 0, 3]。

NLP 里用在哪
一篇文档的"词频清单"就是一个向量；计算机靠比较向量来比较文本。
学到什么程度
理解"向量 = 数字列表"、会算长度即可。行列式、线性方程组可跳过。

点积与向量夹角

必学

对应位置相乘再求和，一个数字衡量两个向量"方向有多一致"。

NLP 里用在哪
所有相似度计算的第一块积木。
学到什么程度
会按公式手算一个 4 维点积即可。几何证明可跳过。

余弦相似度

必学 · 核心

cos θ = A · B|A| × |B|

两个向量夹角的余弦：1 表示方向完全相同，0 表示无关。

NLP 里用在哪
文本相似度、语义检索、文档聚类的标配。你必须能向导师讲清楚它。
学到什么程度
会用 + 能解释"为什么用余弦而不是直接比距离"（只看方向不看长短，长短文章可公平比较）。推导过程可跳过。

矩阵与矩阵乘法

必学

把向量排成表格就是矩阵；乘法规则是"行点列"。

NLP 里用在哪
词袋矩阵、词向量表、Transformer 的注意力，本质上全是矩阵乘法。
学到什么程度
知道维度规则（m×n 乘 n×k）、见过一次 2×2 手算即可。逆矩阵、秩可暂缓。

转置与单位矩阵

了解即可

转置 = 沿对角线翻面；单位矩阵 = 乘法里的"1"。

NLP 里用在哪
代码里到处是 A.T 和 I，认识符号、读到不慌即可。
学到什么程度
五分钟看完就走。

SVD 奇异值分解

推荐 · 推导可跳

把任何大矩阵拆成三个矩阵，保留最重要的几个"方向"，其余丢掉。

NLP 里用在哪
潜在语义分析（LSA）用它把"词-文档"矩阵压缩成主题；是一切降维方法的思想源头。
学到什么程度
知道它是"压缩矩阵、提取主题"的工具即可。如何求解完全可跳过。

特征值与对角化

可跳过

找到矩阵变换中"方向不变"的那些特殊向量。

学到什么程度
应用向暂时完全用不到；走研发向时再回来学，毫无心理负担。

② 概率论与统计 优先级 ★★

语言天生是随机的——下一个词是什么，永远带点运气。概率论就是描述这种不确定性的语言。

概率与条件概率

必学

P(下一个词是"猫" | 前文是"我养了一只…")——语言模型的全部秘密就写在条件概率里。

NLP 里用在哪
从老式的 n-gram 到 GPT，都在做同一件事：估计条件概率。
学到什么程度
理解 P(A|B) 的含义和乘法公式。测度论可跳过（请放心跳过）。

朴素贝叶斯

推荐

"朴素"地假设词与词互不影响，然后反推文本属于哪个类别。

NLP 里用在哪
垃圾邮件过滤、情感分类的经典基线，几行代码就能跑。
学到什么程度
能用自己的话讲清思路即可，公式推导可跳过。

假设检验与 p 值

推荐 · 科研刚需

p 值 = 假如两组真的没差别，出现现在这么极端数据的概率；p < 0.05 就拒绝"没差别"的假设。

NLP / 语言学里用在哪
比较两位作家、两个时代的用词差异是否显著——语料库论文的审稿人一定会问。
学到什么程度
理解逻辑链（原假设 → 统计量 → p 值 → 结论），不背公式表。各检验的推导可跳过。

卡方检验

推荐

数一数"预期 vs 实际"差多少，判断两组频数差异是否显著。

NLP / 语言学里用在哪
语料库语言学最常用的显著性检验，搭配 2×2 列联表使用。
学到什么程度
会用软件算出结果并正确解读即可。手工计算过程可跳过。

常见分布：二项、正态、Zipf

了解即可

词频分布有个著名规律：Zipf 定律——少数词出现极多，大量词只出现一两次。

学到什么程度
知道 Zipf 定律这个趣闻，能解释"为什么高频词都是功能词"，足够了。

大数定律与中心极限定理

可跳过

样本够大，平均数会稳定下来，且近似服从正态分布。

学到什么程度
知道名字和上面这句话就够了，证明请直接跳过。

③ 高等数学 优先级 ★

好消息：对应用向来说，高数只需要两个词——导数和梯度。它们帮你理解"训练模型"到底在干嘛，而不是用来做题。

导数 = 变化率

必学概念

函数在某一点"变化有多快"，图像上就是斜率。

NLP 里用在哪
"训练"就是不断问：把参数挪一点点，错误是变多还是变少？——这就是在用导数。
学到什么程度
建立直觉即可，不求会算。求导法则可跳过。

梯度 = 最陡上坡方向

必学概念

把很多参数的导数打包成一个向量，它指向"变差最快的方向"；反着走，就叫"梯度下降"。

NLP 里用在哪
你听说过的所有"训练大模型"，核心循环就是这一句话。
学到什么程度
能解释"为什么梯度下降要反方向走"即可。偏导数计算可跳过。

链式法则

了解即可

复合函数逐层求导；"反向传播"就是它在大网络里的机械化应用。

学到什么程度
记住"逐层求导"四个字，读科普文章就够用了。

积分

可跳过
学到什么程度
应用向完全不需要。

泰勒展开、极限证明、多元微积分

可跳过
学到什么程度
应用向不需要；研发向第 1–2 个月回头系统补。
✂️ 现在就可以放心跳过的清单：行列式与线性方程组、逆矩阵、特征值对角化、测度论、各种分布的推导、积分、泰勒展开、多元微积分、极限的 ε-δ 定义。等真的用到再回来查，一点都不晚——先动手做出来，再回头补原理，是文科生学技术最快的路。

numpy · 向量运算

推荐

把"一串数字"交给 numpy，相似度十行搞定——这就是数学板块里余弦相似度的落地。

cosine.py
import numpy as np

def cosine(a, b):
    return a @ b / (np.linalg.norm(a) * np.linalg.norm(b))

doc1 = np.array([2, 1, 0, 3])   # 文档 1 的词频向量
doc2 = np.array([1, 1, 1, 2])   # 文档 2 的词频向量
print(cosine(doc1, doc2))       # 0.909 —— 相当相似

spaCy 与 stanza · 文本工具入门

推荐

现成的工业级工具：分词、词性标注、词形还原、命名实体识别，一行加载。

spacy_demo.py · 英文
# 终端执行: pip install spacy
# 终端执行: python -m spacy download en_core_web_sm
import spacy

nlp = spacy.load("en_core_web_sm")
doc = nlp("Chomsky argued that language is innate.")

for token in doc:
    print(token.text, token.pos_, token.lemma_)   # 词 / 词性 / 原形

for ent in doc.ents:
    print(ent.text, ent.label_)   # 实体识别: Chomsky PERSON
stanza_demo.py · 中文
# 终端执行: pip install stanza
import stanza
stanza.download("zh")   # 首次运行会下载中文模型，耐心等

nlp = stanza.Pipeline("zh", processors="tokenize,pos,lemma")
doc = nlp("语言是人类独有的能力。")
for sentence in doc.sentences:
    for word in sentence.words:
        print(word.text, word.pos, word.lemma)

模块 04 · 观念

NLP 概念

不推导、不实现，只求你真的明白每个概念在说什么。读完这一页，你可以自信地听懂一场 NLP 讲座，也听得懂工程师同事在说什么。

词袋 Bag of Words

约 5 分钟

打个比方：把一篇文章拆成一堆词，全部倒进一个袋子，只数每个词出现了几次，完全不管顺序。

例子
「我喜欢语言学」→ {我: 1, 喜欢: 1, 语言学: 1}
为什么重要
这是把文字变成数字的第一步——计算机不识字，只认数字。
局限
「我爱你」和「你爱我」在词袋里一模一样，语序信息全丢了。

TF-IDF

约 10 分钟

打个比方：一个词重要不重要，看两点——它在这篇文章里出现得多不多（TF），以及它是不是"烂大街"的词（IDF）。「的」到处都有，不值钱；「语料库」只在少数文章出现，很值钱。

用途
关键词提取、文本相似度、搜索引擎的祖师爷。
一句话总结
TF-IDF = 出现得多 × 别处少见的词，才是这篇文章的真面目。

词向量 Word Embedding

约 15 分钟

打个比方：给每个词一个"语义坐标"，意思相近的词在地图上住得近。「国王」和「女王」是邻居，「国王」和「午饭」相距十万八千里。

著名的魔法
king − man + woman ≈ queen：语义关系变成了坐标运算。
代表方法
Word2Vec、GloVe；今天大模型的底层仍保留着这个思想。

Token

约 10 分钟

打个比方：大模型读书时不是按"词"也不是按"字"，而是按 token——一种介于字和词之间的碎片。「人工智能」可能被切成「人工」+「智能」两块。

冷知识
为什么大模型数不对 "strawberry" 里有几个 r？因为它看到的不是字母，而是 token。
实用
API 按 token 计费；"上下文长度"说的也是 token 数。1 个汉字 ≈ 1–2 个 token。

Transformer 与注意力

约 20 分钟

打个比方：读到「它」这个字时，注意力机制让模型回头看全句，自己判断「它」指的是前面的哪个词，并给相关的词分配更高的"关注度"。

划时代之处
老方法（RNN）一个字一个字顺着读；Transformer 让所有词同时互相看（并行计算），又快又能抓住长距离关系。GPT、BERT 里的 T 都指它。
需要数学吗
不需要。你只需记住一个词：注意力（Attention）。

上下文窗口 Context Window

约 5 分钟

打个比方：模型的"工作记忆"。它一次只能看见窗口里的内容——比如 8K、128K 个 token。

后果一
文章太长，开头的部分会被"挤出去"，模型就忘了。
后果二
于是有了 RAG：先检索出最相关的几段，再塞进窗口让模型读。别被术语吓到——本质是"先划重点，再答题"。

预训练与微调

约 10 分钟

打个比方：预训练 = 让模型读完整个图书馆，学会"接话"；微调 = 给这个博学的人做岗前培训，适应你的具体任务。

与你相关
你平时写提示词（prompt）调教 ChatGPT，是一种零成本的"轻量调教"，很多时候不必真的微调。

⚠️ 幻觉 Hallucination

科研必读

大模型会一本正经地编造不存在的文献、页码和数据——因为它的本职是"接最像的话"，不是"查证事实"。

科研守则
AI 给的每一条参考文献，都必须亲手核实原文；关键论证，不让 AI 代劳。审稿人迟早会找上门。

项目一 · 文本相似度计算

难度 ★☆☆约 30 分钟

用到的概念：词袋 · TF-IDF、余弦相似度

原理白话版：把每篇文档变成"词袋向量"（中文按单字切分，不用分词也能用），再用 TF-IDF 给字加权，最后算两两之间的余弦相似度。数值越接近 1，两篇文本"话题"越像。

🧪 在线实验室 · 改掉下面的文本再点按钮
similarity.py · Python 版（sklearn）
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

docs = [
    "春天的西湖游人如织，苏堤春晓桃红柳绿，断桥边杨柳依依。",
    "夜晚的西湖别有韵味，湖面倒映着灯火，断桥与雷峰塔遥遥相望。",
    "梯度下降是训练神经网络最常用的优化算法，沿着损失下降的方向更新参数。",
    "反向传播利用链式法则逐层计算梯度，神经网络通过不断更新参数来降低损失。",
    "杭帮菜讲究清淡鲜嫩，西湖醋鱼与龙井虾仁是最有名的两道菜。",
]

# 中文没有空格分词，改用"字符级"分析器（按单字切分，短文本效果最好）
vec = TfidfVectorizer(analyzer="char")
matrix = vec.fit_transform(docs)
sim = cosine_similarity(matrix)

for i in range(len(docs)):
    for j in range(i + 1, len(docs)):
        print(f"文档{i+1} vs 文档{j+1}: {sim[i][j]:.3f}")
# pip install scikit-learn 后即可运行
延伸挑战：① 把默认文档换成你论文的三段摘要，看它们像不像；② 增加第 6 篇文档；③ 想一想：为什么"杭帮菜"那篇和西湖那两篇也有一点像？（提示：共享了「西湖」二字）

项目二 · Burrows-Delta 文体计量

难度 ★★☆约 45 分钟

用到的概念：向量 · z 分数、词频分布、计算文体学

原理白话版：每位作者都有自己的"高频字指纹"——有人爱用「之乎者也」，有人离不开「真的超特别」。把各文本最常用字的出现比例转成 z 分数，再算待判定文本与每位作者平均风格的平均差距（Delta）。Delta 越小，文风越像。这就是计量文体学判定《伟大的小说 X》作者归属的经典方法。

🧪 在线实验室 · 三位虚构作者 + 一段待判定文本
burrows_delta.py · Python 版（纯标准库）
import statistics
from collections import Counter

def chars(text):                      # 只留汉字，丢掉标点
    return [c for c in text if "\u4e00" <= c <= "\u9fff"]

corpus = {                            # 每位作者至少 2 段样本
    "作者A": ["……样本1……", "……样本2……"],
    "作者B": ["……样本1……", "……样本2……"],
}
unknown = "……待判定文本……"
top_n = 30                            # 取最高频的前 30 个字

# 1. 每个文本统计"字频比例"
freqs = {}
for samples in corpus.values():
    for t in samples:
        cs = chars(t); n = len(cs) or 1
        freqs[t] = Counter({c: v / n for c, v in Counter(cs).items()})
cs = chars(unknown); n = len(cs) or 1
freqs["待判定"] = Counter({c: v / n for c, v in Counter(cs).items()})

# 2. 取全语料最高频的 top_n 个字
total = Counter()
for c in freqs.values():
    total.update(c)
top = [w for w, _ in total.most_common(top_n)]

# 3. 对每个字做 z 分数（跨文本标准化）
z = {}
for t, f in freqs.items():
    vals = [f[w] for w in top]
    mean = statistics.mean(vals)
    sd = statistics.pstdev(vals) or 1e-9
    z[t] = {w: (v - mean) / sd for w, v in zip(top, vals)}

# 4. 每位作者取样本平均 z 分数，算 Delta 距离
for author, samples in corpus.items():
    profile = {w: statistics.mean(z[t][w] for t in samples) for w in top}
    delta = statistics.mean(abs(z["待判定"][w] - profile[w]) for w in top)
    print(f"{author}: Delta = {delta:.3f}")

# Delta 越小，待判定文本与该作者的文风越接近。
延伸挑战：① 把你研究对象的文本分两组粘进来，判定一段待测文字；② 把高频字数从 30 改成 60（改脚本里的 top_n），结果更稳还是更噪？③ 注意：每个作者至少要 2–3 段各 300 字以上的文本，样本太短结果不可信——示例语料只是为了演示机制。

项目三 · 语料处理实验台

难度 ★☆☆约 30 分钟

用到的概念：Token、类符 / 形符比（TTR）、Zipf 定律

原理白话版：这是语料库语言学最基础的一套操作——把文本切成 token，然后统计：总共多少字、多少类符（不同的词）、类符/形符比（词汇丰富度）、平均句长、最高频的词是哪些。把它们粘进论文的"语料描述"部分，就是最标准的做法。

🧪 在线实验室 · 粘贴你自己的语料
corpus_stats.py · Python 版（jieba 真分词）
import re
import jieba
from collections import Counter

with open("corpus.txt", encoding="utf-8") as f:
    text = f.read()

# jieba 是最常用的中文分词库: pip install jieba
words = [w for w in jieba.lcut(text) if re.search(r"[\u4e00-\u9fff]", w)]
counter = Counter(words)

print("总字数(含标点):", len(text))
print("总词数:", len(words))
print("类符数:", len(counter))
print("TTR 类符/形符比:", round(len(counter) / len(words), 3))
print("\n前 20 个高频词:")
for w, n in counter.most_common(20):
    print(f"{w}\t{n}")
延伸挑战：① 粘贴你自己最长的一篇语料（几千字），看看高频词表；② 切换"字符 / 二元组"两种模式，对比 TTR 变化；③ 高频词从第 2 名往后逐名递减得很快吗？——恭喜，你亲眼见到了 Zipf 定律；④ 长文本请用下方 Python 脚本，网速和浏览器内存都更友好。
